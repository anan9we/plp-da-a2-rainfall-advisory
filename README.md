# Rainfall Analysis and Planting Advisory

- This project analyses monthly rainfall data from five Kenyan counties using Python and NumPy to identify rainfall patterns, annual totals, wettest months and dry months.
- To run the analysis, install dependencies using `pip install -r requirements.txt`, open `rainfall_analysis.ipynb` in Jupyter Notebook or VS Code, and run all cells.
- The planting advisory recommends April–May for Nairobi, Nakuru, Kisumu and Mombasa, and November–December for Machakos, with Machakos results treated cautiously because of two imputed rainfall values.
